<h1 align="center">easygram</h1>

<p align="center"><a href="README_EN.md">English</a> · Русский</p>

Easygram — неофициальный клиент Telegram для Android. Он основан на открытом коде Telegram и развивает привычный мессенджер дополнительными возможностями. Сейчас основное внимание уделено записи видеосообщений — «кружков».

## Собственный camera pipeline

На Android 9 и новее Easygram записывает кружки через отдельный camera pipeline на базе Camera2. Запись интегрирована в интерфейс чата, но использует собственную обработку камеры, предпросмотра, звука и видео. На более старых версиях Android остаётся прежний путь записи.

Что это даёт:

- **Больше контроля над качеством.** В настройках видеосообщений можно выбрать разрешение, частоту кадров, битрейт видео и звука, максимальную длительность и параметры обработки изображения.
- **Настройку под камеру устройства.** Доступность режимов проверяется для фронтальной и основной камер. Неподдерживаемые варианты помечаются как недоступные и не сохраняются.
- **Более аккуратное начало записи.** Запись запускается после готовности камеры и первого кадра предпросмотра. Дополнительная задержка помогает не включать в готовое видео скачок экспозиции в момент запуска.
- **Удобное переключение камер.** Можно запоминать камеру, использованную при последней записи, и начинать следующий кружок с неё. Если настройка выключена, запись начинается с фронтальной камеры.
- **Настройку света и фокуса.** Доступны параметры экспозиции, баланса белого, фокусировки, стабилизации и других режимов камеры — если их поддерживает устройство.

Настройки находятся в **Настройки → Видеосообщения**. Поведение камеры и доступность отдельных функций могут различаться между устройствами.

## Что дальше

Easygram продолжит развиваться: планируются новые улучшения записи кружков, качества изображения и удобства использования приложения. Изменения будут появляться постепенно.

### Обновления APK

Новые сборки проверяют [GitHub Releases](https://github.com/webarmour/Easygram/releases) напрямую. Релиз с флагом **Pre-release** предназначен для beta (`io.github.webarmour.easygram.beta`), обычный опубликованный релиз — для stable (`io.github.webarmour.easygram`). Черновики игнорируются. Проверка происходит при возобновлении приложения не чаще раза в час; вручную её можно запустить из настроек.

Старые установленные версии, которые ещё читают `updates/beta.json` и `updates/stable.json`, требуют разового обновления feed для перехода на этот механизм. Для этого после загрузки APK можно использовать `Tools/update_feed.py`; затем новые версии будут видеть следующие GitHub Releases без изменения JSON.

## Исходный код и лицензия

Easygram — независимый проект, не связанный с командой Telegram. Основа приложения — [Telegram для Android](https://github.com/DrKLO/Telegram). Условия распространения исходного кода приведены в файле [LICENSE](LICENSE).
